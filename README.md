# Conflict Resolution Trainer

A branching-scenario simulator for practicing workplace conflict. You read a
tense situation, choose how to respond, and see how your choice plays out.
After each choice the trainer names the conflict strategy you used, rates how
well it worked, and explains why.

**Try it:** https://williamthe5thc.github.io/ConflictGame/

I built it because I want to help people handle conflict better, and practice
in a safe setting is one way to get there: you can try an approach that would
be risky at work, see what happens, then go back and try another.

## What it teaches

The feedback is built on the Thomas-Kilmann model of five conflict strategies:
collaborating, compromising, competing, accommodating and avoiding. Learners
see that each one has a cost, and that the best choice depends on the
situation. The scenarios also practice listening, separating people from
problems, and knowing when to move a conversation off email.

## Scenarios

| Scenario | Level | Time | The situation | Status |
|---|---|---|---|---|
| The Email Misunderstanding | Beginner | 5-8 min | A terse email, a defensive reply that copies the manager, and a team that feels the tension | Playable |
| The Resource Competition | Intermediate | 8-12 min | Two urgent projects need the same designer by Friday | Being written |
| The Performance Gap | Advanced | 10-15 min | A team member's work is slipping, and the team is noticing | Being written |

The Email Misunderstanding branches through 20 choices to several different
endings. The other two scenarios have some branches still to write, so the
menu lists them as "Coming soon" until every path is finished.

## How it works

- **No wrong answers, only consequences.** Every choice moves the story, and
  the feedback explains what it did to the relationship and the work.
- **Go back.** Learners can return to a decision and try another strategy.
- **Progress is saved** in the browser, so a scenario can be finished later.
- **Meet the people involved.** Each scene shows the scenario's cast with
  their names and roles, so learners know who they are dealing with.
- **Accessibility:** screen-reader announcements for story changes, and
  animations turn off for people who ask their device for reduced motion.

## Built with

Plain HTML, CSS and JavaScript, with no framework and no build step. Each
scenario is a JSON file (`scenarios/`), so a new scenario can be written
without touching the code. The game checks that every choice leads to a scene
before it starts a scenario. Character portraits and the office scene are SVG;
the portraits are generated by `tools/make-portraits.py`.
Hosted on GitHub Pages.

```
index.html            the app shell
js/game-engine.js     moves through a scenario's decision tree
js/ui-manager.js      renders scenes, choices and feedback
js/storage-manager.js saves progress in the browser
js/app.js             starts everything
scenarios/*.json      the scenarios and their feedback
tools/make-portraits.py  draws the character portraits in one style
```

To run it locally, serve the folder with any static server, for example
`python3 -m http.server`, then open http://localhost:8000.
